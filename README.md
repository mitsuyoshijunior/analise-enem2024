# Análise Diagnóstico ENEM 2024

Este projeto apresenta análises do ENEM 2024, explorando médias, desvio padrão, desempenho por região, dependência e alunos com médias acima de 600 pontos.  
O projeto utiliza Python (pandas) e Power BI para visualização interativa.

---

## Objetivo do Projeto

- Avaliar o desempenho dos alunos do ENEM 2024 em diferentes dimensões: região, dependência administrativa e médias por matéria.  
- Identificar padrões de desempenho e desigualdades educacionais.  
- Produzir visualizações interativas para facilitar a interpretação dos dados.  
- Demonstrar habilidades em **análise de dados**, **Python/pandas** e **Power BI**.

---

## Tecnologias Usadas

- **Python 3.x** (bibliotecas: pandas, numpy)  
- **Power BI Desktop** (visualizações interativas, gráficos de barras, tree maps, cartões, etc.)  
- **Google Colab** (para notebooks interativos e reprodutíveis)  
- **Git/GitHub** (versionamento e portfólio online)

## Estrutura do repositório

analise-diagnostico-enem2024/
│

├─ data/

│ ├─ raw/ → CSVs brutos (não incluídos; link para download oficial)

│ └─ processed/ → CSVs processados do ENEM 2024 (baixar do Drive)

│

├─ notebooks/ → Notebooks Python para análise

├─ reports/ → Relatório Power BI (.pbix)

├─ images/ → Prints das abas do Power BI

└─ README.md → Este arquivo


### 1️ - Dados Brutos (`data/raw`)

- Os dados brutos oficiais do ENEM 2024 podem ser baixados no site do INEP:  
[Microdados ENEM 2024](https://www.gov.br/inep/pt-br/areas-de-atuacao/avaliacao-e-exames-educacionais/enem/microdados)  
- **Não incluídos no repositório** devido ao tamanho (2GB).  


### 2 - Dados Processados (`data/processed`)

- Os arquivos processados foram preparados para facilitar a análise e reduzir o tamanho, mantendo apenas os dados essenciais.  
- **Arquivos hospedados no Google Drive** devido ao tamanho (250 MB).  

### 3 - Notebooks (notebooks/)

- Contêm códigos em Python para análise dos dados do ENEM 2024.
- Preparados para rodar no Colab ou localmente, desde que a variável caminho esteja corretamente configurada.

### 4 - Relatório Power BI (reports/)

- Arquivo .pbix completo, com todos os dados já importados, pronto para interatividade.
- Quem baixar o PBIX poderá abrir e interagir com todos os gráficos sem precisar de arquivos externos.

Para abrir:
1 - Abra o Power BI Desktop
2 - Carregue o arquivo ENEM_2024.pbix

### 5 - Imagens (images/)
- Prints das abas do Power BI usados para demonstração no portfólio.
- Não substituem o PBIX, apenas servem como referência visual.
